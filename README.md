# Корпоративный календарь

Python, CustomTkinter и SQLite. В этой ветке к модулю задач добавлена переписка.

Установка зависимостей из папки проекта:

```powershell
py -m pip install -r requirements.txt
```

`py main.py --user ID` открывает переписку существующего пользователя.
`py main.py --user ID --event EVENT_ID` открывает задачи выбранного события.
Вместо `ID` и `EVENT_ID` укажите реальные номера записей в общей базе.
Кнопка «Новый диалог» открывает список пользователей и поиск по имени, фамилии или логину.
Enter отправляет сообщение, Shift+Enter добавляет новую строку.

Пробные данные не создаются. В пустой базе ещё нет пользователей и событий:
их добавляют модули регистрации и событий. В существующей базе данные сохраняются.
Аргумент `--user` нужен для отдельного запуска и не заменяет авторизацию.
В общем приложении окно открывается через `ChatWindow(app, database, current_user)`.

`chat/service.py` работает с сообщениями, `chat/window.py` содержит окно чата.
Доступ к событиям проверяет `event_service.py`, таблицы создаёт `db.py`.
Чат события появляется автоматически по записи в `events`; список участников
задаётся через `event_members`. Создание и изменение событий подключаются из модуля событий.
