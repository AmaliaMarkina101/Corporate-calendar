# Корпоративный календарь

Python, CustomTkinter и SQLite. В этой ветке к модулю задач добавлена переписка.

Установка зависимостей из папки проекта:

```powershell
py -m pip install -r requirements.txt
```

`py main.py --user ID` открывает переписку существующего пользователя.
`py main.py --user ID --event EVENT_ID` открывает задачи выбранного события.
Вместо `ID` и `EVENT_ID` укажите реальные номера записей в общей базе.
Кнопка «Новый диалог» открывает список пользователей и поиск по имени, фамилии или логину.
Enter отправляет сообщение, Shift+Enter добавляет новую строку.

Пробные данные не создаются. В пустой базе ещё нет пользователей и событий:
их добавляют модули регистрации и событий. В существующей базе данные сохраняются.
Аргумент `--user` нужен для отдельного запуска и не заменяет авторизацию.
В общем приложении окно открывается через `ChatWindow(app, database, current_user)`.

`chat/service.py` работает с сообщениями, `chat/window.py` содержит окно чата.
Доступ к событиям проверяет `event_service.py`, таблицы создаёт `db.py`.
Используется схема из заданий: `groups`, `group_members`, `events`
с полями `author_id`, `access_type`, `group_id` и таблица `event_access`.
Группа у события необязательна. `private` доступно автору,
`limited` — автору и пользователям из `event_access`, `public` — всем пользователям.
По заданию переписки для отправки в чат достаточно доступа к событию.

В `event_access` сохраняются права `read`, `edit_tasks`, `full`.
`read` разрешает просмотр и комментарии к задачам, `edit_tasks` — работу со своими
задачами, `full` — изменение любых задач события. Исполнителей назначает тимлид
из участников своих групп. Автор события имеет полный доступ; в публичном
событии остальные пользователи могут создавать и изменять свои задачи.

Поиск работает по `users.username` — полю «имя/логин» из задания.
Если там записаны имя и фамилия, найти человека можно по любой из этих частей.
Отдельные поля имени и фамилии не требуются.

База прежней версии с `teams` и `visibility` автоматически не преобразуется.
Сохраните её копию отдельно и подключите базу со схемой из задания.
Программа сообщает о старой схеме до внесения изменений в неё.
