# Corporate Calendar: запуск приложения

```bash
pip install -r requirements.txt
source ~/venv_cal/bin/activate
python main.py
```

База `corporate_calendar.db` создаётся рядом с `main.py` при первом запуске (одна на календарь, задачи и чат).
Чтобы начать с нуля, закройте приложение и удалите этот файл.

## Вход и роли
- Регистрация: имя, фамилия, логин, email, пароль. Пароли хранятся только в виде хеша (PBKDF2-SHA256 с солью).
- **Первый зарегистрированный пользователь становится администратором**, остальные участниками.
- Администратор в меню «Пользователи и роли» назначает роль тимлида. Тимлид создаёт группы и назначает исполнителей.

## Демо-данные для проверки под разными ролями
```bash
python seed_demo.py          # только на пустой базе
```
Логины `admin`, `alex` (тимлид), `maria`, `ivan`, пароль у всех `demo1234`. У `maria` создаётся задача
с напоминанием через 1 минуту: войдите под ней и подождите, появится окно будильника.

## Как устроено
| Файл | Что делает |
|---|---|
| `main.py` | окно приложения, смена экранов, открытие окон модулей без дублей |
| `auth_service.py`, `auth_ui.py` | регистрация, вход, роли / экраны входа и регистрации |
| `menu_ui.py` | главное меню, список событий для задач, управление ролями |
| `alarm_service.py`, `alarm_ui.py` | будильник: проверка раз в 20 секунд, всплывающее окно |
| `calendar_module/`, `tasks_module/`, `chat_module/`, `core/` | модули команды без изменений |

Будильник берёт `reminder_time` невыполненных задач, где вы исполнитель. «Понятно» или «Открыть задачи»
помечают напоминание показанным (таблица `task_reminders_shown`). «Через 5 мин» откладывает его до
перезапуска приложения. Напоминания, пропущенные при закрытом приложении, показываются при следующем входе.
